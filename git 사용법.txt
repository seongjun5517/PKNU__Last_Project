git 사용법

0. 폴더에 깃허브 연결하기
git init (깃허브를 연결할수있게 만들기)
git remote add origin 깃허브링크
git pull origin 깃허브에 있는 브랜치 이름
(만약 로컬피씨에 브랜치가 있는데 깃허브에는 없는 브랜치면 삭제)

1. branch 생성
git branch 생성할 브랜치 이름

2. 생성한 브랜치 github에 올리기(로컬에서 생성한 브랜치)
git push --set-upstream origin 생성한 브랜치 이름 

2-1. 생성한 브랜치 로컬에 올리기(깃허브 홈페이지에서 생성한 브랜치)
git fetch origin
git checkout 생성한 브랜치 이름

3. 로컬에 있는 작업한 파일 깃허브에 올리기
git add .
git commit -m "변경사항에 대한 코멘트"
git push


깃허브 홈페이지에서 브랜치를 생성후 로컬PC에서 그 브랜치를 받아온다
그 다음 그 브랜치에서 작업을 한 후 Merge할 브랜치에 add, commit, push한 후 pr을 하고 최종 Merge할 브랜치에 Merge 후 그 브랜치는 삭제한다.

4. 사용한 브랜치 삭제
git checkout 합친파일이있는 브랜치 (dev)
git pull
git branch -d 홈페이지에서 생성한 브랜치



사이클
이슈 생성-> 이슈생성에서 development에서 create a branch 클릭 후 브랜치 생성(복사해두기) -> 작업 후 add, commit, push 작업 진행
-> compare&pull request 클릭 -> create pull request 클릭 -> merge pull request 클릭 -> confirm merge 클릭 -> delete branch 클릭
-> git bash로 이동 후 합칠 브랜치로 이동 -> 사용한 브랜치 삭제 -> 이슈 생성
gitflow / trunk-based
